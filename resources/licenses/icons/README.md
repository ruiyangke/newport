# Icon notices

The desktop embeds file icons and process icons from
`crates/newport-gpui/assets`. Packaging copies their existing notices and public
source records into this directory without changing their contents:

- `file-icons/LICENSE-symbols` and `file-icons/LICENSE-lucide` accompany file
  icons.
- `process-icons/LICENSE.md`, `process-icons/DISCLAIMER.md`, and
  `process-icons/SOURCES.json` accompany the Simple Icons collection.
- `process-icons/LICENSE-opencode` and `process-icons/SOURCE-opencode.json`
  accompany the OpenCode icon.

`FILES.json` is the packaged notice inventory, relative to the asset directory.

The source records identify upstream revisions, versions, and brand guidance
where supplied. Keep the notices and source records with the embedded assets
when updating or redistributing them.
