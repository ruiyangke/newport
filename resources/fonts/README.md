# Terminal symbols

Newport bundles [Symbols Nerd Font Mono 3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly) to display terminal prompt icons without a separate font installation. Terminal text uses GPUI Kit's resolved platform monospace family (normally Menlo on macOS and Consolas on Windows). Measurement and painting use the same face; Monaco remains a macOS glyph fallback.

The bundled font is covered by [its accompanying license](NERD-FONTS-LICENSE). Preserve that notice when redistributing the font.
