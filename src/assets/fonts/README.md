# Terminal symbols

Porthop bundles [Symbols Nerd Font Mono 3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly) to display terminal prompt icons without a separate font installation. Menlo and Monaco provide the terminal text faces.

The bundled font is covered by [its accompanying license](NERD-FONTS-LICENSE). Preserve that notice when redistributing the font.
