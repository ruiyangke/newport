### Improved

- Linux apps that need X11 open on any server with XWayland 23.1 or newer.
- If a server has no XWayland, the app's message has an Install button. Install it, then open the app again.
- When a Linux app can't open, Newport shows the start of its error. Show full error shows the rest.
- Setup checks for Zenity, which Chromium and other apps use for dialogs.
- Old X11 apps show text at the right size on Retina screens.
- SSH approval messages for port forwards and terminals say only what to do.

### Fixed

- Very wide dialogs, like Chromium's profile prompt, now open.

### Changed

- The Application support setting for Linux apps is gone.
- Projects in Connections no longer show a card when you hover over them.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux apps need Newport Pro or a free trial, and are available on macOS only.
