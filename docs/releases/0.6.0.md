Linux apps (Remote apps) are on macOS only in this release.

### New

- Copy files and folders between Finder and Linux apps, like file managers, through the clipboard.
- Linux app windows have minimize, maximize and close buttons, a window menu when you right-click the title bar, and resize from their edges.
- The editor shows code actions and uses project settings from VS Code and Zed.
- The editor has common shortcuts: save, close tab, open file, show files, switch tabs, open the terminal, rename, find references and format. They never reach terminals.

### Improved

- Linux apps use much less memory on your server, especially windows you aren't using.
- When a Linux app can't open, Newport tells you why. If the app is already open, the new window opens there.
- Opening many Linux apps on a small server no longer closes all of them when memory runs out.
- Setup checks for what Linux apps need on your server, like sound and file dialogs, and tells you what to install.
- File dialogs work in Snap and Flatpak apps.
- Text you copy in a Linux app stays on the clipboard after you close the app.
- The Remote apps page tries again on its own when it can't reach the server.
- To clone a repository, paste its URL. Newport names the project and picks the folder.
- Create repository makes a new folder for you.
- Add repository names the project after the folder you choose.
- Click anywhere on a project to open it. Right-click it for more actions.
- When a clone fails, Newport shows what Git said, and how to fix a server with no certificates.
- A commit that needs your name and email says so, with a button to set them.
- Containers work with Podman. If Podman isn't turned on, Newport shows the command that turns it on.
- Newport asks before you close a terminal or quit while a command is still running.
- Quit works while a dialog is open.

### Changed

- To run a command as a Linux app, type it in a Newport terminal. The Run command button and saved commands are gone from Remote apps.
- Language server settings for a project come from its `.vscode/settings.json` or `.zed/settings.json`. Newport no longer reads `.newport/lsp.json`.
- Terminals no longer have controls for Linux apps. Apps you start from a terminal open in their own windows, and a problem with them never stops the terminal.

### Before you install

macOS asks whether Newport may find devices on your local network. Allow it so Newport can reach servers on your network. On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux apps need Newport Pro or a free trial, and are available on macOS only.
