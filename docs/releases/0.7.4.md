### New

- A coding agent that reports its status to the terminal, such as Claude Code 2.1.295 or later, shows it on its tab: a spinner while it works, a yellow dot when it waits for you, a green dot when it finishes while you're on another tab, and a red dot when it stops with an error.
- Drag a terminal tab or a project file tab to move it, or choose **Move tab left** or **Move tab right** in the **Workspace** menu. Each computer keeps its own order of a server's terminals, and a project's file tabs open again in the same order.
- The title bar shows the SSH round trip to the server beside its connection status. It turns yellow when the connection is slow, and red when it's very slow.

### Improved

- A shell open on several computers is drawn at one size on all of them, the size of the computer where you last typed, clicked or scrolled in it, as tmux does. Before, each computer drew it at its own size, so output written for another computer's width looked broken.
- A terminal tab grows with its title, so more of it fits before it's cut off.
- Shells keep running when a program's cleanup kills the process that started it. On servers with systemd, each shell runs in its own scope, so when the server runs out of memory and kills one shell, Newport still shows how it ended.
- Update snapshots leave out the server metrics history and Remote apps launchers, so they're smaller and quicker to make.

### Fixed

- A Git change that the server refused or that never reached it no longer stops every later Git change in the project.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows installers aren't code-signed yet. Linux apps need Newport Pro or a free trial.
