### New

- Type a Linux app's name, like `chromium`, in a Newport terminal and it opens in its own window on your computer.
- Paste images into OpenCode on the server.

### Improved

- Pasting images on the server no longer needs extra software installed there.
- Turning on clipboard sync sets up pasting on the server, even if you skipped it during setup.
- Keys like Ctrl+F now go to the program running in the terminal.
- Newport uses fewer keyboard shortcuts of its own, so they don't get in your way.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux desktop apps need Newport Pro or a free trial, and are available on macOS only.
