### Open source

- Newport's source code is now public on GitHub under the GNU Affero General Public License 3.0. You can read it, build it and send changes. Remote apps stays part of Newport Pro.
- Newport includes the licenses of every library it ships with, in **Licenses/THIRD-PARTY-NOTICES.txt** inside the app.

### Improved

- On servers where sudo is allowed without a password, port discovery keeps sudo for the whole connection, so every scan shows which process listens on each port, including processes of other users. Connection details show **Elevation: Active**.
- When sudo needs a password or isn't allowed, connection details say so: **Elevation: Unavailable · sudo needs a password or isn't allowed**. Before, they showed **Waiting to retry** and tried again later.
- Code highlighting uses each language's official highlighting rules, so it matches what other editors show. Protocol Buffers, Swift, C# and CMake files are now highlighted, and C++ and TypeScript highlight everything C and JavaScript do.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows installers aren't code-signed yet. Linux apps need Newport Pro or a free trial.
