### New

- Connect through. In a server's settings, choose Direct, Jump host or Proxy command. A jump host is one of your other servers. A proxy command works like ssh's `ProxyCommand`.
- Newport imports `ProxyJump` and `ProxyCommand` from your `~/.ssh/config`. A jump host is imported along with the servers that use it.
- Clean up forwards. On the Ports page, the broom button deletes saved forwards that are switched off and have nothing listening on the server.
- Cmd+T opens a terminal tab. Cmd+1 to Cmd+8 go to a tab, and Cmd+9 goes to the last one. On Windows, use Ctrl+Alt+1 to Ctrl+Alt+9.
- Settings shows the build you're running and when it was built.

### Improved

- Each server shares one SSH sign-in across terminals, files, forwards and apps. Newport opens more connections only when it needs them and stays within the server's session limit.
- Setup tries the server check again while the server can't be reached yet.
- Installing Needle always finishes. If a newer Needle is already on the server, Newport uses it.
- Port forward messages are shorter.
- Pages that load quickly no longer flash a loading placeholder.
- On Windows, Newport's header is the title bar, with its own minimize, maximize and close buttons. It matches Newport's light or dark appearance, and Snap Layouts open from Maximize.

### Fixed

- The first connection after installing Newport on a Mac no longer fails with "No route to host".
- Opening a Linux app no longer fails with "Refresh the server connection before opening applications."
- New terminal tabs take the lowest free number, so numbering starts again after you close tabs.
- When a server has the most terminals it can open, the new-tab button is turned off instead of showing an error. Each server has its own limit.

### Changed

- Setup no longer checks for Zenity.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux apps need Newport Pro or a free trial, and are available on macOS only.
