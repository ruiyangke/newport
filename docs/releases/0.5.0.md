### New

- Open Linux apps from your server in their own windows on your Mac, with Newport Pro.
- Sign in to your Newport account from the app.
- Get code completion and error checking in the editor.
- Copy text from programs in the terminal, including inside tmux.
- Switch between terminal tabs with the keyboard.

### Improved

- The parts of Newport on your server now update themselves.
- Restarting to install an update on macOS works more reliably.
- Linux apps keep sharing the clipboard after you reconnect.
- Fixed keys that didn't always reach the terminal.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux desktop apps are available on macOS only.
