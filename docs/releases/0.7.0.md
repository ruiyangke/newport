### New

- Uninterruptible terminals. Your shells keep running on the server, like tmux, with nothing to start or attach. Quit Newport, lose the connection or close your laptop: the shell and its programs carry on. When you come back, each tab shows its shell as it is now.
- Every computer connected to a server shows the same shells. Start a build on one computer and check it on another. Holding the pointer over a tab shows which other computers have it open.
- Linux apps keep running. Each server account has one set of running apps, shown on one computer at a time. Typing in one of the server's terminals, opening an app or choosing **Show here** brings them to this computer. Quitting Newport leaves them running.
- Linux apps on Windows. **Remote apps** now works on Windows as well as on the Mac.
- Linux apps as separate apps. **Open as separate apps** is on by default. On a Mac, each app gets its own Dock icon, menu bar and Cmd-Tab entry. On Windows, each app gets its own taskbar button and icon, which you can pin or add to the Start menu.
- See what is behind each port. **Connections** shows the process, system service or container listening on each port of the server. Choose a port's name to see its addresses, processes and services. **Discovery details** shows what the last scan could and couldn't see.
- Clean up forwards. When saved forwards say **Destination not observed**, on or off, the **Clean up forwards** button appears in the **Connections** toolbar. It lists them and deletes them when you confirm.
- Add server reads your SSH config. When you leave **SSH host**, Newport asks OpenSSH which settings your config gives that host, including `Match` and `Include` blocks, and fills in the username, port, key file and proxy command in fields you haven't typed in. This needs OpenSSH on your computer, which comes with macOS and is an optional feature on Windows.
- A failed connection offers your SSH config's proxy command. When connecting fails and your SSH config uses a different proxy command for the host, setup shows it with **Use this command**.

### Improved

- A service listening on several addresses shows as one port. **Choose server address** lets you pick the one to forward.
- **Integrations** shows the Needle version each connection uses, and the version included with Newport when the two differ, with a short build ID when two builds share a version.
- Needle updates itself when compatible. When a feature finds Needle older than your Newport, Newport updates it at once.
- **Close** on a terminal tab ends a shell that an older, incompatible Needle build holds. If Needle can't start a new tab's shell, the tab opens an ordinary shell with a **This shell won't keep running** notice.
- Copying in a Linux app or a terminal on the server reaches your computer's clipboard, and pasting into X11 apps keeps accented and non-Latin text.
- Apps you run from a terminal get sound, file dialogs and your desktop settings, as apps opened from **Remote apps** do.
- A Linux app without an icon gets a letter tile in the Dock, the taskbar and the Start menu.
- **Always on** forwards say plainly that they keep reconnecting whenever the connection drops.
- Saving a server, a forward or a permission is instant, and Newport starts faster. Servers and forwards are saved in `profiles.json`, and only SSH passwords and your sign-in are encrypted, with the profile's key. The first start moves them from the earlier files, keeps your key, and leaves `profiles.stronghold` in the data folder, so an earlier version still opens it. Delete it once you no longer need an earlier version.
- New guides for Account and Pro, and for Settings. The other guides are rewritten to be shorter and match the app.

### Fixed

- A forward reaches a server app whether it listens on IPv4 or IPv6. Ports listening on `[::]` or only on IPv4 no longer show **Unreachable**.
- Scrolling in a Linux app stops when you stop, without extra momentum.
- Animations in Linux apps no longer build up blocky artifacts.
- File dialogs stay above the Linux app that opened them.

### Before you install

Update Newport on every computer that uses the same server. This version updates Newport's helper on your servers, even while it runs, and older versions of Newport can't share a server with it.

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux apps need Newport Pro or a free trial.
