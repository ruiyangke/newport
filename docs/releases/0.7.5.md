### Improved

- Typing in a terminal shows sooner. A tab shows output as it arrives, sends everything you type or paste at once, and keeps sending what you type while a busy program is slow to take its output.
- Remote apps respond faster. Typing, clicks and scrolling reach the app as they happen, a small change such as a typed character is shown without waiting for sound to catch up, and frames are encoded and decoded off the paths that handle input. File uploads to a Remote app are quicker too.
- Connections shows one row per program and port. A container's ports are listed once, under Containers, for Docker and Podman, and each says which port in the container it goes to.
- A project terminal's shell starts in the project folder, instead of typing `cd` first.
- Opening Newport goes back to the project you were on.
- **Find a process** on the Overview searches every process on the server, not only the 50 it shows.
- Needle's processes are named `newport-agent` in `ps` and on the Overview.
- A language server that hasn't answered for 15 seconds says so, with **Restart**, instead of showing **Starting** for ever.
- A server's new key or password keeps Needle's approval and integrations. Only a different destination starts setup again.

### Fixed

- A terminal tab no longer shows as failed on one computer while its shell still runs. A tab attaches again after connection failures the server recovers from, and stops only when its shell ends.
- A busy shell no longer drops its tab: Newport holds back output the shell's tab isn't taking yet, and waits for an app that stalls.
- Sharing the clipboard with a server no longer stops after one copy fails. A late reply to a cancelled paste is ignored, and other failures reconnect sharing instead of ending it.
- A project folder that no longer exists says so once, and file errors read as one plain message.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows installers aren't code-signed yet. Linux apps need Newport Pro or a free trial.
