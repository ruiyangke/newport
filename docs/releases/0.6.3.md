### Improved

- If your SSH agent didn't approve a sign-in, Newport asks again when your computer wakes, unlocks or changes network.
- Press Return in a waiting terminal tab to ask your SSH agent again.

### Fixed

- Terminals and Always on forwards no longer stay failed when your SSH agent didn't approve a sign-in. They wait, and reconnect as soon as the server does, for example after Server → Test connection or a new terminal tab.
- When a server reconnects, open projects load a folder that failed while it was away and start their language servers again.
- If your SSH agent stops answering, for example while 1Password restarts, Newport tries again instead of treating it as a declined sign-in.

### Before you install

On macOS, you need Apple silicon and macOS 14 or later. Windows versions are experimental and not code-signed yet. Linux apps need Newport Pro or a free trial, and are available on macOS only.
